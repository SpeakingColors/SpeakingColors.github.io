About Scratch Cat Duo

Scratch Cat Duo is a free, open source creative audio plugin (VST3) by Studio 87. It is a test build: it installs and runs, but has not been checked on every machine yet. The source code and all releases are on GitHub. If you want to build on it, fork it.
