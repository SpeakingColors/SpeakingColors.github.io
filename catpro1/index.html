About Behringer Pro-1 patch book

Behringer Pro-1 patch book is a free, open source hardware controller plugin (VST3, Linux) by Studio 87. It is a test build: it installs and runs, but has not been checked on every machine yet. The source code and all releases are on GitHub. If you want to build on it, fork it.
